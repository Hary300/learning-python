# Challenge 02 — Even or Odd

**Difficulty:** Easy

**Language:** Python

## Description

Create a Python program that determines whether a given integer is an even number or an odd number.

The program should receive an integer and display the result.

## Requirements

1. Ask the user to enter an integer.
2. Check whether the number is even or odd.
3. Display the appropriate message.

## Example

**Input:**

```text
Enter a number: 7
```

**Expected Output:**

```text
7 is an odd number.
```

Another example:

**Input:**

```text
Enter a number: 12
```

**Expected Output:**

```text
12 is an even number.
```

## Constraints

- Use `input()` to receive user input.
- Convert the input into an integer.
- Use an `if-else` statement.
- Use the modulo operator (`%`).

## Concepts Practiced

- User input
- Type conversion (`int()`)
- Conditional statements (`if-else`)
- Arithmetic operators (`%`)
- Comparison and logical thinking
