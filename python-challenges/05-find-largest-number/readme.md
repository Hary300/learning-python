# Challenge 05 — Find the Largest Number

**Difficulty:** Easy

**Language:** Python

## Description

Create a Python program that finds the largest number in a list of integers.

The program should examine every element and determine which number has the highest value.

## Requirements

1. Create a list containing several integers.
2. Initialize a variable to store the largest number.
3. Iterate through the list.
4. Compare each number with the current largest number.
5. Update the largest number when a bigger value is found.
6. Display the largest number.

## Example

**Input:**

```python
numbers = [12, 45, 7, 89, 23, 56]
```

**Expected Output:**

```text
Largest number: 89
```

## Constraints

- Use a `for` loop.
- Use an `if` statement.
- Do not use `max()`.
- Do not use sorting methods.
- Your solution should also work with negative numbers.

## Concepts Practiced

- Lists
- For loops
- Conditional statements
- Comparison operators
- Variables
- Updating variable values
- Iteration
