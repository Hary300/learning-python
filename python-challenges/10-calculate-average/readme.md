# Challenge 10 — Calculate Average

**Difficulty:** Easy

**Language:** Python

## Description

Create a Python program that calculates the average
of all numbers in a list.

The program should iterate through the list,
calculate the total sum, and divide it by the
number of elements.

## Requirements

1. Create a list containing several numbers.
2. Initialize a variable to store the total sum.
3. Iterate through the list.
4. Accumulate the total sum.
5. Calculate the average.
6. Display the final result.

## Example

**Input:**

numbers = [10, 20, 30, 40, 50]

**Expected Output:**

Average: 30.0

## Constraints

- Use a for loop.
- Use an accumulator variable.
- Use len() to determine the number of elements.
- Do not use sum().
- Do not use statistics.mean().
- Assume the list contains at least one number.

## Concepts Practiced

- Lists
- For loops
- Accumulator variables
- len()
- Arithmetic operators
- Division
- Variables
