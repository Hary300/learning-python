# Challenge 12 — Count Words

**Difficulty:** Easy

**Language:** Python

## Description

Create a Python program that counts the number of words in a sentence entered by the user.

The program should identify individual words and display the total word count.

## Requirements

1. Ask the user to enter a sentence.
2. Separate the sentence into individual words.
3. Count the total number of words.
4. Display the result.

## Example 1

**Input:**

```text
Enter a sentence: Python is easy to learn
```

**Expected Output:**

```text
Total words: 5
```

## Example 2

**Input:**

```text
Enter a sentence: I love programming
```

**Expected Output:**

```text
Total words: 3
```

## Constraints

- Use `input()` to receive user input.
- Use `split()` to separate words.
- Do not use regular expressions.
- Do not manually count the words.
- Multiple spaces between words should not affect the result.

## Concepts Practiced

- Strings
- User input
- String methods (`split()`)
- Lists
- `len()`
- Variables
