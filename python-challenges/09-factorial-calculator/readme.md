# Challenge 09 — Factorial Calculator

**Difficulty:** Easy

**Language:** Python

## Description

Create a Python program that calculates the factorial of a non-negative integer entered by the user.

Factorial is the product of all positive integers from 1 up to the given number.

For example:

5! = 5 × 4 × 3 × 2 × 1 = 120

Remember: 0! = 1.

## Requirements

1. Ask the user to enter a non-negative integer.
2. Calculate its factorial using a loop.
3. Display the final result.
4. Handle the special case when the input is zero.

## Example 1

**Input:**

```text
Enter a number: 5
```

**Expected Output:**

```text
Factorial of 5 is 120.
```

## Example 2

**Input:**

```text
Enter a number: 0
```

**Expected Output:**

```text
Factorial of 0 is 1.
```

## Constraints

- Use `input()` to receive user input.
- Convert the input into an integer.
- Use a `for` loop.
- Use an accumulator variable.
- Do not use `math.factorial()`.
- Do not use recursion.
- Assume the user enters a non-negative integer.

## Concepts Practiced

- User input
- Type conversion (`int()`)
- For loops
- `range()`
- Accumulator variables
- Arithmetic operators
- Conditional statements
