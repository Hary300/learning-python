# Challenge 08 — Multiplication Table

**Difficulty:** Easy

**Language:** Python

## Description

Create a Python program that generates a multiplication
table for a number entered by the user.

The program should display the multiplication results
from 1 to 10.

## Requirements

1. Ask the user to enter an integer.
2. Generate a multiplication table from 1 to 10.
3. Calculate the multiplication result for each iteration.
4. Display each multiplication equation and its result.

## Example

**Input:**

Enter a number: 5

**Expected Output:**

5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50

## Constraints

- Use input() to receive user input.
- Convert the input into an integer.
- Use a for loop.
- Use range() to control the iterations.
- Do not manually write all ten multiplication equations.

## Concepts Practiced

- User input
- Type conversion (int())
- For loops
- range()
- Arithmetic operators
- String formatting
- Iteration
