# Challenge 07 — Reverse a String

**Difficulty:** Easy

**Language:** Python

## Description

Create a Python program that reverses a given string.

The program should take a word or sentence as input and display its characters in reverse order.

## Requirements

1. Ask the user to enter a word or sentence.
2. Reverse the input string.
3. Display the reversed string.

## Example 1

**Input:**

```text
Enter a text: Python
```

**Expected Output:**

```text
Reversed text: nohtyP
```

## Example 2

**Input:**

```text
Enter a text: Hello World
```

**Expected Output:**

```text
Reversed text: dlroW olleH
```

## Constraints

- Use `input()` to receive user input.
- Use a `for` loop.
- Do not use slicing (`[::-1]`).
- Do not use `reversed()`.
- Preserve the original capitalization and spaces.

## Concepts Practiced

- Strings
- For loops
- String concatenation
- Variables
- Iteration
- Building a new string
