# Challenge 03 — Compare Two Numbers

**Difficulty:** Easy

**Language:** Python

## Description

Create a Python program that compares two integers
and determines which number is greater.

The program should also identify when both numbers
are equal.

## Requirements

1. Ask the user to enter two integers.
2. Compare the two numbers.
3. Determine which number is greater.
4. If both numbers are equal, display an appropriate message.

## Example 1

**Input:**
Enter first number: 15
Enter second number: 8

**Expected Output:**
15 is greater than 8.

## Example 2

**Input:**
Enter first number: 5
Enter second number: 12

**Expected Output:**
12 is greater than 5.

## Example 3

**Input:**
Enter first number: 10
Enter second number: 10

**Expected Output:**
Both numbers are equal.

## Constraints

- Use input() to receive user input.
- Convert inputs into integers.
- Use if, elif, and else.
- Do not use max() or min().
- Do not use sorting methods.

## Concepts Practiced

- User input
- Type conversion (int())
- Conditional statements (if-elif-else)
- Comparison operators (>, <, ==)
- Variables
- Logical thinking
