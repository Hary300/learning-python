# Challenge 21 — Find the Second Largest Number

## Description

Create a Python program that finds the second largest distinct number in a list.

The second largest number must be different from the largest number.

## Requirements

1. Create a list containing at least two distinct numbers.
2. Create two variables:
   - `largest`
   - `second_largest`
3. Initialize both variables appropriately.
4. Iterate through the list using a `for` loop.
5. Update `largest` and `second_largest` based on the current number.
6. Display the second largest number.

## Example 1

**Input:**

```python
numbers = [10, 5, 20, 8, 15]
```

**Output:**

```text
Second largest number: 15
```

## Example 2

**Input:**

```python
numbers = [10, 10, 8, 5, 8]
```

**Output:**

```text
Second largest number: 8
```

## Constraints

- Use a `for` loop.
- Use conditional statements.
- Do not use `sort()` or `sorted()`.
- Do not use `max()`.
- Do not use `set()`.
- Do not create another list.
- Assume the list contains at least two distinct numbers.

## Concepts Practiced

- Lists
- For loops
- Conditional statements
- Multiple variables
- Comparison operators
- Updating variable values
