# Challenge 16 — Count Positive, Negative, and Zero

## Description

Create a Python program that counts how many positive numbers, negative numbers, and zeros exist in a list.

## Requirements

1. Create a list containing positive numbers, negative numbers, and zeros.
2. Create three counter variables:
   - `positive_count`
   - `negative_count`
   - `zero_count`
3. Iterate through the list using a loop.
4. Use conditional statements to determine each number's category.
5. Increase the appropriate counter.
6. Display the final counts.

## Example

**Input:**

```python
numbers = [10, -5, 0, 8, -2, 3, -1, 0]
```

**Output:**

```text
Positive numbers: 3
Negative numbers: 3
Zeros: 2
```

## Constraints

- Use a `for` loop.
- Use `if`, `elif`, and `else`.
- Use counter variables.
- Do not use `count()` or other built-in counting methods.
- Do not use list comprehensions.

## Concepts Practiced

- Lists
- For loops
- Conditional statements
- Counter variables
- Increment operators (`+=`)
