# Challenge 01 — Number Counter

**Difficulty:** Easy

**Language:** Python

## Description

Create a Python program that counts how many numbers in a list are greater than zero.

The program should receive a list of integers and calculate how many of them are positive numbers.

## Requirements

1. Create a list containing several integers (positive, negative, and zero).
2. Iterate through the list.
3. Check whether each number is greater than zero.
4. Count how many positive numbers exist.
5. Display the final count.

## Example

**Input:**

```python
numbers = [10, -5, 0, 8, -2, 3, -1]
```

**Expected Output:**

```text
Positive numbers: 3
```

## Constraints

- Use a `for` loop.
- Use an `if` statement.
- Do not use `count()` or other built-in counting shortcuts.

## Concepts Practiced

- Lists
- For loops
- Conditional statements
- Comparison operators
- Variables and counters
