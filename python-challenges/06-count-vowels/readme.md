# Challenge 06 — Count Vowels

**Difficulty:** Easy

**Language:** Python

## Description

Create a Python program that counts how many vowels exist in a given string.

The program should examine each character and determine whether it is a vowel.

Vowels consist of: `a, e, i, o, u`.

## Requirements

1. Ask the user to enter a word or sentence.
2. Iterate through each character in the input.
3. Check whether each character is a vowel.
4. Count the total number of vowels.
5. Display the final count.

## Example 1

**Input:**

```text
Enter a text: Hello World
```

**Expected Output:**

```text
Total vowels: 3
```

## Example 2

**Input:**

```text
Enter a text: Python Programming
```

**Expected Output:**

```text
Total vowels: 4
```

## Constraints

- Use `input()` to receive user input.
- Use a `for` loop.
- Use an `if` statement.
- Use a counter variable.
- The program must handle uppercase and lowercase vowels.
- Do not use `count()`.

## Concepts Practiced

- Strings
- String iteration
- For loops
- Conditional statements
- Membership operator (`in`)
- String methods (`lower()`)
- Counter variables
