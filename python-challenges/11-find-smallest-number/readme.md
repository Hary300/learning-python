# Challenge 11 — Find the Smallest Number

**Difficulty:** Easy

**Language:** Python

## Description

Create a Python program that finds the smallest number in a list of integers.

The program should examine every element and determine which number has the lowest value.

## Requirements

1. Create a list containing several integers.
2. Initialize a variable to store the smallest number.
3. Iterate through the list.
4. Compare each number with the current smallest number.
5. Update the smallest number when a smaller value is found.
6. Display the smallest number.

## Example

**Input:**

```python
numbers = [12, 45, 7, 89, 23, 3]
```

**Expected Output:**

```text
Smallest number: 3
```

## Constraints

- Use a `for` loop.
- Use an `if` statement.
- Do not use `min()`.
- Do not use sorting methods.
- Your solution must also work with negative numbers.

## Concepts Practiced

- Lists
- For loops
- Conditional statements
- Comparison operators
- Variables
- Updating variable values
- Iteration
