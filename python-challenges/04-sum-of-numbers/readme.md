# Challenge 04 — Sum of Numbers

**Difficulty:** Easy

**Language:** Python

## Description

Create a Python program that calculates the total
sum of all integers in a list.

The program should iterate through the list and
accumulate the total value.

## Requirements

1. Create a list containing several integers.
2. Initialize a variable to store the total sum.
3. Iterate through the list.
4. Add each number to the total.
5. Display the final result.

## Example

**Input:**

numbers = [5, 10, 15, 20, 25]

**Expected Output:**

Total sum: 75

## Constraints

- Use a for loop.
- Use an accumulator variable.
- Do not use sum().
- Do not use other built-in summation shortcuts.

## Concepts Practiced

- Lists
- For loops
- Variables
- Accumulators
- Arithmetic operators
- Iteration
